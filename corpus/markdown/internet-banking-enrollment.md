# Internet Banking Enrollment Guide

Effective date: 2026-02-02

## Eligibility and enrollment steps

Any customer with an active current or savings account and a registered mobile number may enroll in internet banking. The employee prints the enrollment form, verifies the national ID, and the activation code is sent by SMS to the registered mobile number.

Use the steps below for each enrollment:

1. Confirm that the account is active and not dormant, blocked or restricted. Dormant accounts must be reactivated first.
2. Check the registered mobile number on the customer record against the number the customer states. The number must be an 11-digit Egyptian mobile number starting with 010, 011, 012 or 015.
3. Verify the original national ID and compare the photo and signature with the Bank records.
4. Print the enrollment form, ask the customer to read and sign it, and keep the signed copy with the customer file.
5. Create the digital banking service request under the customer reference, for example CUS-318004, selecting the internet banking channel.
6. Submit the request for supervisor approval. Supervisor approval is required for all service requests before execution, so the activation code is not sent until the request is approved.

Customers who have no registered mobile number cannot be enrolled until the number is added. Changing the registered mobile number needs a branch visit with a national ID and is a separate request.

Joint accounts may be enrolled only for the account holder who is present and has been verified. Each joint holder enrolls separately.

## Activation timeline

Internet banking activation codes expire after 24 hours. If the code expires the customer must request a new code at the branch or through the call centre.

Tell the customer at the counter what to expect:

1. After the supervisor approves the request, the activation code is sent by SMS to the registered mobile number.
2. The customer should log in to the internet banking site and enter the code within 24 hours of receiving it.
3. After the code is accepted, the customer chooses a username and password. Staff must never choose these on the customer's behalf or write them down.

If the 24 hours pass, the code no longer works. Do not tell the customer to keep trying. Create a new digital banking request for a new activation code, with the same customer reference and channel, and submit it for supervisor approval. A customer who calls the call centre can also be issued a new code after identity checks there.

Example: customer CUS-662190 enrolled on Sunday but only tried the code on Tuesday and sees an error. The employee checks the request history, confirms the original code was sent more than 24 hours earlier, and raises a new code request.

Advise customers to enter the code soon after receiving it and to keep the phone with the registered number nearby. Remind them that the Bank never asks for the activation code by phone, chat or email.

## Enrollment request and approval

Every enrollment is a digital banking service request. The request needs the channel (internet banking), the issue type, the customer reference and the registered mobile number in the correct 11-digit format.

The employee prepares the request and the system validates it. A request with an invalid mobile number or a missing channel cannot be submitted. Device change is not a valid issue type for internet banking, because it applies only to the mobile app.

After submission, a supervisor reviews the request. The supervisor may approve it, correct it and approve it, or reject it with a reason. A supervisor may not approve a request they submitted themselves, so if the supervisor prepared the enrollment, another supervisor must approve it.

Once approved, the request is executed once. If the employee tries to run it again, the system returns the original record and does not send a second code. This prevents multiple activation messages.

Keep these items with the case:

- The signed enrollment form.
- The ticket reference returned after execution.
- The note of the identity document checked.

From the third quarter, the enrollment form is printed from the branch portal and includes the customer consent section. Check the current Branch Notice Board for form updates, and ask the supervisor if anything looks unclear.

## Troubleshooting and escalation

Common problems and the correct response:

- The SMS does not arrive. Check the registered mobile number on the record, ask whether the phone has signal, and check that the request was executed. If the number is wrong, raise a registered mobile number update first.
- The customer says the code is invalid. Check whether more than 24 hours have passed, and whether the customer typed the newest code if more than one was sent.
- The customer is locked out of internet banking after enrollment. Verify identity and raise a digital banking request. A supervisor must approve it before the unlock.
- The customer wants to enroll a business or minor account. These cases are not covered here; refer to the supervisor.
- The customer's name or ID on the record does not match the document. Do not enroll. Follow the Customer Identification and Verification Standard.

Escalate to the digital banking help desk through the supervisor if a request stays in the pending state for more than one working day, or if the same customer reference shows three or more failed enrollments. Include the customer reference, for example CUS-318004, and the ticket references, but never include passwords, activation codes or full account numbers.

Finally, explain to the customer how to protect the account: do not share the username or password, do not log in from public computers, and contact the branch immediately if an unexpected activation message arrives.
